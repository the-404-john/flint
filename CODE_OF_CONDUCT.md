# Code of Conduct

## Project Standards

### Expected Behavior
- **Collaboration**: Attempt to reach a collaborative solution before
escalating conflicts.

- **Respect**: Respect that most design and implementation choices
involve compromises, as there is rarely a one *"correct"* answer.

- **Constructive Critique**: Keep critiques focused on the code
and the technical implications, not the individual.

### Unacceptable Behavior
- **Discrimination**: Refrain from any form of bias or judgment
based on race, ethnicity, age, gender identity, sexual orientation,
disability, personal appearance, or other similar characteristics.

- **Privacy Violation**: Posting or threatening to post
the personally identifying information of others without explicit
permission (*"doxing"*).

- **Disruptive Behavior**: Trolling, flaming, baiting, spamming, or
any other annoying behavior intended to distract from the project’s
goals.

> [!NOTE]
> Please avoid using sexual aliases or other nicknames that might
> detract from a friendly, safe and welcoming environment for all.

## Project Responsibilities
Project maintainers are responsible for clarifying standards
of acceptable behavior and must take fair, corrective action
in response to any violations.

Maintainers reserve the right to remove, edit, or reject any
contributions — including comments, commits, code and issues —
that do not align with this [Code of Conduct].

Furthermore, maintainers may temporarily or permanently ban
contributors for behavior deemed inappropriate, threatening, offensive,
or harmful.
